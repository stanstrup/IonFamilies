# IonFamilies

[![R-CMD-check](https://github.com/stanstrup/IonFamilies/actions/workflows/R-CMD-check.yaml/badge.svg)](https://github.com/stanstrup/IonFamilies/actions/workflows/R-CMD-check.yaml)
[![pkgdown](https://github.com/stanstrup/IonFamilies/actions/workflows/pkgdown.yaml/badge.svg)](https://stanstrup.github.io/IonFamilies/)

Isotope and adduct annotation of LC-MS feature groups.

One compound gives many LC-MS features: its quasi-molecular ion, other
adducts, in-source fragments and the isotopes of all of these, its *ion
family*. `groupFeatures()` from
[MsFeatures](https://github.com/RforMassSpectrometry/MsFeatures) and
[xcms](https://github.com/sneumann/xcms) groups features that come from the
same compound. **IonFamilies** annotates the ion family within each group:

* `annotateIsotopes()` finds isotope patterns with
  `MetaboCoreUtils::isotopologues()`.
* `annotateAdducts()` finds adducts and fragments by neutral-mass voting with
  a rule list (by default from [commonMZ](https://github.com/stanstrup/commonMZ)).
  All supported hypotheses are kept and ranked, because the annotations are
  hints and a missed true annotation is worse than a coincidental one.

Results go into `featureDefinitions()` of the `XcmsExperiment`: `isotopes`
and `adduct` hold the labels as text in CAMERA's syntax, and the grouping is
the `feature_group` column from `groupFeatures()`. All hypotheses are kept in
the list column `adduct_hints` (`adductHints()`), and the parameters in
`metadata(x)$IonFamilies`.

```r
library(xcms)
library(MsFeatures)
library(IonFamilies)

x <- groupFeatures(x, SimilarRtimeParam(diffRt = 3))
x <- groupFeatures(x, AbundanceSimilarityParam(threshold = 0.7, transform = log2))
x <- annotateIsotopes(x, IsotopologueParam(ppm = 10))
x <- annotateAdducts(x, AdductVoteParam(polarity = "positive", nBest = 3))
featureDefinitions(x)[, c("feature_group", "isotopes", "adduct")]
adductHints(x)
```

```r
remotes::install_github("stanstrup/IonFamilies")
```

## Status

Early development (0.99.x, the Bioconductor pre-release numbering). Documentation: <https://stanstrup.github.io/IonFamilies>. The package follows the
[RforMassSpectrometry](https://www.rformassspectrometry.org/) and Bioconductor
conventions so that it could be contributed there later.

* Parts of the code were written with the help of an AI assistant
  (Claude, Anthropic) and reviewed by the maintainer. This is disclosed as
  the RforMassSpectrometry contribution guidelines ask.

* Releases are made by semantic-release from the commit messages (GitHub
  Actions, `.github/workflows/release.yaml`); versions stay in 0.99.x.

  `.github/workflows/pkgdown.yaml`.
